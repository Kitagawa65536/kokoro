Place mouth overlay PNGs here:

- `closed.png`: closed mouth overlay
- `half.png`: half-open mouth overlay
- `open.png`: open mouth overlay

Use transparent PNGs centered on the mouth. For the bundled character image,
the default mouth anchor is approximately `x=1152`, `y=1385` in the original
`2304x3072` image coordinate space. A `320x180` transparent canvas with the
mouth centered is a good starting size.
